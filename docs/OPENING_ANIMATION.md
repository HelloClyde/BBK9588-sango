# 木门打开过渡

此前9588片头播放资源003的整张门图，停留后直接进入主菜单；时间轴播放完成并不表示存在门扇移动。上一轮木色素材验证只覆盖整图、时间轴返回和菜单显示，没有覆盖左右门扇运动。

现于 `sango_game_lifecycle` 中接入 `src/sango_intro.c`：原片头自然结束后，复制当前门图，准备主菜单，再将左右半幅向两侧移出画面。中间逐渐露出菜单。每步移动6像素，共20步；专用窗口定时器4请求30ms间隔，实际耗时取决于固件及绘制速度。原片头或开门期间的按键、点击可跳过。跳过、自然结束和画布分配失败都落在完整菜单上。

绘制使用固定SDK的兼容context、矩形复制和窗口定时器接口。每帧在已有消息画布上拼好再显示，只额外保存一张门图；结束释放保存画布并停止定时器4。两个不同透明键的复制确保门图中的黑色、白色等RGB565颜色不丢失。没有新增开门图片帧，也没有改动木色素材、原LIB、存档或其他动画的时间轴。门扇尺寸由现有240×320整图等分，最后一帧为完整菜单。

## 原版对照范围

本地原始9288S `三国霸业.exe` 的SHA-256是 `4eafbd3c59b64bf56fb810e47de43cb9d1075530801a8f991cf007f510954f9c`。其资源003为160×240单张门图；与原9588版的两条播放指令相同，分别是 `[0,0,40,40,0]` 和 `[0,0,3,3,0]`。

本轮在独立NAND副本上运行未修改的9288S程序，约5.17秒内抓取110帧：第2帧出现门图，第44帧出现菜单，没有抓到两者之间可见的门扇滑移。这个结果不能代表其他9288S版本。当前开门效果按用户记忆和需求补充，不声称是已观察到的9288S原版逐帧复刻。原始EXE和NAND不随仓库发布。

## 验证

- `python tools/test_intro.py`：41项编译后MIPS检查，覆盖左右半幅采样坐标、完整离屏帧、20步运动、仅定时器4推进、真实触摸识别、点击/长按/按键跳过、拖动不误触、失败回退、定时器与画布释放，以及实际启动函数接线。
- 原生C200固件模拟器：8项检查，关闭图及开门距离0/30/60/90/120逐像素核对；再运行实际定时开门控制器，观察到多个准确的中间位置及最终菜单。使用独立NAND、按原字节载入的BDA/LIB/CLR和不进入交付BDA的独立场景脚本，不代表真机测试。
