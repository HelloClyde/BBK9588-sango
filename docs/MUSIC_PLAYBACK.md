# 音乐播放改进

三首完整曲目仍为22050Hz单声道IMA ADPCM，文件与alpha.6一致；常规构建直接使用仓库压缩资源，无需原FLAC或FFmpeg。

alpha.7使用命名SDK接口，在打开播放时显式设置衰减值24，关闭后恢复此前设置。压缩数据按4KiB预读，播放器一次最多提交1024字节16位PCM，通过固件队列反压控制速度；专用10ms定时器与游戏输入/动画定时器隔离。停止时使用有界等待及静音收尾。

普通构建不启用诊断写文件。开发定位可用 `python build.py --music-diagnostics`，它只在内存计数并在结束后输出一次；该诊断版不用于Release。

用户反馈D1诊断版真机有声，之后指出卡顿；这说明该诊断环境可出声，不能单独证明原无声的唯一原因。随后预读和提交预算已通过编译MIPS回归，最新整包的真机流畅度仍待复验。原生模拟器历史音频证据保留在 `validation/music-native-validation.json`，不冒充本版完整真机测试。

65项当前编译MIPS检查覆盖三首全部11509218样本的独立FFmpeg散列、解码选块、循环、切歌、短读/短写、反压、错误、停止及定时器隔离，见 `validation/alpha7-music-validation.json`。该检查建模SDK音频和文件边界，不等于硬件性能测量。
