# 触摸操作

触摸与实体方向键、确定、返回可以混合使用。点击在抬笔时触发一次；移动达到8个屏幕像素即进入拖动，该次抬笔不再触发点击。

| 界面 | 操作 |
| --- | --- |
| 主菜单、剧本菜单 | 直接点击对应的图片按钮，立即进入该项，无需先用方向键选中 |
| 君主、武将、宝物列表 | 点击可见条目；滑动可以改变选择或切换属性列 |
| 指令、技能及战斗选项菜单 | 点击对应文字行；点击菜单框外取消 |
| 战略地图 | 点击城池所在格子进入原有指令流程；点击空地只移动光标 |
| 地图视野 | 按住地图拖动，视野跟随移动并限制在地图边界；松手不会下达命令。轻点空地只移动光标，不使用边缘点击滚动 |
| 战斗人物 | 点击己方可行动武将；再点击合法目的地进入操作菜单。点击原地可直接打开该武将菜单 |
| 战斗目标 | 先点攻击或技能，再点目标；原有范围、阵营、地形、状态和资源规则继续检查 |
| 信息、查找 | 点击底栏原有按钮；信息页整页显示并保持，点击或按键返回；战场概览可再点击关闭 |
| 战斗／战略菜单 | 点击底部君主头像，等同原有返回键入口；原有后续菜单照常处理。长按地图不会确认操作 |
| 数值输入 | 点击要修改的数位，再点“减少／增加”；“确定／返回”完成或取消 |
| 存读档槽 | 点击三项实际槽位中的对应行，进入原有读取或写入流程 |

拖动起点必须在地图区域内。战略彩色视口为240×232、7×7逻辑格；灰度回退按224×224换算。战场视口为240×208、15×13格。点击和拖动均按当前视口换算世界坐标，底栏及摘要不会作为战场格子处理。

触摸层在 `src/sango_touch.c` 与 `include/sango_touch.h`，不进入原游戏存档。按下／抬起通过SDK窗口消息跟踪，拖动只在按下期间使用 `bda_gui_touch_position()` 读取校准坐标；不混用全局raw事件队列。独立20ms触摸定时器不会计入游戏/动画时钟，长按使用SDK单调25ms计数器。窗口回调消费触摸消息，避免同一次触摸又进入固件默认按键处理。

验证范围和确切BDA见 [验证记录](VALIDATION.md)。编译MIPS检查、受控固件触摸流程、完整战役和真机验证是不同范围；本轮不宣称完整战役或真机已验证。

战略地图的横向/纵向连续拖动、战斗选择人物/目的地/目标时拖动、反向拖回、边界限制及松手不确认，已在C200模拟器以连续硬件输入轨迹验证。此前仅发送三个大幅跳点的诊断没有覆盖连续手势，不能据此判断SDK不支持拖动。真机仍待实测。
