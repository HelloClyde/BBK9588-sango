# 素材入口

所有可编辑素材、生成母图、提示词和来源记录集中在本目录。
解包素材已按中文用途分类、命名，全部 ID 与用途对照见 [资源目录](library/资源目录.md)。

| 目录 | 用途 | 构建用途 |
| --- | --- | --- |
| `library/` | 从 9588 `sango.LIB` 完整解包的 87 条资源、1186 张 PNG、动画指令及 7 张战场地图 | 重新生成 `build/sango.lib` |
| `statusbar/` | “信息／查找”底栏的原图参考、GPT Image 母图和 240×36 四灰度目标图 | LIB 资源 17，同时生成战略/战斗 C 内嵌位图 |
| `credits/` | 制作群组参考、母图和 240×320 四灰度目标图 | LIB 资源 18，同时生成 C 内嵌位图 |
| `battle-toolbar/` | 战斗按钮栏的提示词、布局及同源图片 | 当前与 `statusbar/` 共用图片；位置为 y=257 |
| `app-icon/` | 9288S 原图参考、GPT Image 彩色母图及四种原生尺寸 PNG | SDK 编码为 BDA 容器的彩色 VX 图标 |
| `drafts/color9288s/` | 此前保留的三张彩色母图、提示词及原始参考图集 | 草稿，不打入 LIB 或当前 BDA |

LIB 沿用原游戏四级灰度格式，不支持直接放入 RGB 高清母图。彩色应用图标使用 BDA 的 VX 格式，
不会被量化进 LIB。母图保留原生成分辨率，运行时图片按目标尺寸保存。

当前 BDA 从 C 内嵌位图绘制新增底栏和制作群组，以继续兼容旧 `sango.LIB`。
`python build.py` 会从同一份目标 PNG 生成 LIB 的补充条目和这些内嵌数据；
修改目标 PNG 后执行完整构建即可同步。单独运行 LIB 打包命令只生成 LIB，不修改已编译的 BDA。
以后如将补充条目改为运行时读取，须同步修改加载代码并重新验证。

原图与派生图的来源及许可状态见根目录 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
