# 素材入口

所有可编辑素材、生成母图、提示词和来源记录集中在本目录。
解包素材已按代码用途分类、命名，全部 ID 与用途对照见 [资源目录](library/资源目录.md)。
每项调用与选择表依据见 [代码用途核对](library/代码用途核对.md)，未定位调用的012、060、074保留待确认状态。

| 目录 | 用途 | 构建用途 |
| --- | --- | --- |
| `library/` | 从 9588 `sango.LIB` 完整解包的 87 条资源、1202 张 PNG、27 组动画指令及 7 张战场地图 | 重新生成 `build/sango.lib` |
| `statusbar/` | “信息／查找”底栏的原图参考、GPT Image 母图和 240×36 四灰度目标图 | LIB 资源 17，同时生成战略/战斗 C 内嵌位图 |
| `credits/` | 制作群组参考、母图和 240×320 四灰度目标图 | LIB 资源 18，同时生成 C 内嵌位图 |
| `battle-toolbar/` | 战斗按钮栏、9288S 状态行参考、提示词及同源图片 | 当前与 `statusbar/` 共用图片；按钮栏在 y=232，以240×36原尺寸绘制；状态行在 y=208、高24像素；底部268～319行为势力摘要 |
| `color/` | 全部1204帧的语义彩色PNG、18张选用母图、原始图集、提示词和映射目录 | 生成RGB565 `build/sango.clr`，原LIB保留遮罩/动画/数据 |
| `app-icon/` | 9288S 原图参考、GPT Image 彩色母图及四种原生尺寸 PNG | SDK 编码为 BDA 容器的彩色 VX 图标 |
| `music/` | 用户提供的三首FLAC的压缩运行版本、来源及转换参数 | 复制到 `build/music/` 并打入升级ZIP的 `sango-music/`，不进入LIB |
| `drafts/color9288s/` | 此前保留的三张彩色母图、提示词及原始参考图集 | 草稿，不打入 LIB 或当前 BDA |

LIB沿用四灰度格式。游戏内彩色内容另存RGB565 `sango.clr`；应用图标使用BDA的VX格式。
母图保留生成分辨率，游戏运行图片按原生尺寸保存；不改变资源编号、帧顺序和原透明遮罩。

当前BDA优先从CLR绘制彩色底栏/制作群组；缺失或不匹配时用C内嵌灰度位图。
`python build.py` 会从同一份目标 PNG 生成 LIB 的补充条目和这些内嵌数据；
修改目标 PNG 后执行完整构建即可同步。单独运行 LIB 打包命令只生成 LIB，不修改已编译的 BDA。
彩色版从同目录读取 `sango.clr`；其LIB大小和CRC32必须匹配，详见 [彩色资源说明](color/README.md)。

原图与派生图的来源及许可状态见根目录 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
